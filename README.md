# Пепельная Корона

Интерактивное приключение в стиле тёмного средневекового фэнтези для учеников 5–11 классов. Игра рассчитана на 3–8 игроков и примерно 60 минут.

## Играть онлайн

[Открыть «Пепельную Корону»](https://dark-fantasy-dnd.uvpowerman.chatgpt.site)

## Возможности

- четыре оригинальные тактические карты;
- перемещение жетонов мышью и касанием;
- добавление, удаление и подпись жетонов;
- отслеживание текущих и максимальных ОЗ;
- броски d4, d6, d8, d10, d12 и d20;
- автоматическая очередь инициативы;
- карточки четырёх героев и пяти противников;
- подробная шпаргалка ведущего на каждый этап;
- три иллюстрированных финала с последствиями и эпилогами.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Состояние игрового поля хранится в памяти открытой страницы и не синхронизируется между устройствами.
